# Security policy

## Supported versions
Security fixes target the latest release. Historical Windows packages are not guaranteed to receive security backports.

## Report a vulnerability privately
Do not publish exploit details, unpatched vulnerabilities or secrets in public issues. Contact the maintainer privately through the contact method on their GitHub profile, or use GitHub private vulnerability reporting if enabled. Include affected version, minimal reproduction, impact and possible mitigations. No response-time guarantee or bounty is promised.

Report ordinary bugs through GitHub issues.

## Trust and downloads
Download binaries only from the project's GitHub Releases page. Check their SHA256 digests against the checksum file published with the release. These checksums are not cryptographic signatures and do not independently authenticate the publisher. The ngspice engine and dependencies retain their third-party licenses.
